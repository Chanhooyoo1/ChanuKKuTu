
## 🎵 효과음 및 오디오 자원 저작권 안내 (Sound Effects License)

`Server/lib/Web/public/media/` 폴더 내에 포함된 모든 효과음 및 오디오 자원은 본 프로젝트의 자산입니다.

- **개인적 용도 허용:** 개인 학습, 테스트, 로컬 환경에서의 개인 플레이 용도로는 자유롭게 사용이 가능합니다.
- **타 서버 및 외부 사용 금지:** 타 프리서버(공개/비공개 서버 포함)에서의 무단 도용, 적용, 재배포 및 상업적 이용을 엄격히 금지합니다.
- **출처 명시:** 개인 프로젝트 활용 시 원작자 및 본 리포지토리 출처를 밝혀주시기 바랍니다.
